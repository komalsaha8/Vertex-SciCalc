VERTEX - Advanced Scientific Calculator

VERTEX is a responsive and user-friendly scientific calculator web application. It is designed for students and general users who need more than just basic calculations. The application provides scientific functions along with user authentication and a personal dashboard to track calculation history.

Key Features
- Scientific calculation support including trigonometry, logarithms, and exponents.
- Secure user login and registration system using PHP and MySQL.
- Personal dashboard to view and manage calculation history.
- Fully responsive design that works on mobile, tablet and desktop.
- Simple, clean and easy to use interface.

Tech Stack
Frontend: HTML5, CSS3, JavaScript
Backend: PHP
Database: MySQL

How to Run Locally
1. Clone the repository
2. Import database.sql file in phpMyAdmin
3. Start XAMPP server and run the project on localhost

Future Scope
- Graph plotting for mathematical functions
- Unit and currency converter
- Export calculation history as PDF
